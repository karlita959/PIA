# PIA

Demo de agente de IA para aprender programación usando HTML, CSS y JavaScript.

## Cómo abrirlo
Abre el archivo `index.html` en un navegador.

## Descripción
Es una pequeña aplicación estilo chat con respuestas automáticas sobre:
- HTML
- CSS
- JavaScript
- variables
- funciones
- lógica
